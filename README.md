# 🤖 (주)동양 자금팀 AI 프로젝트 저장소 (-AI-)

본 저장소는 (주)동양 자금팀의 **AI 연동 프로젝트 (퇴직연금 통합 관리 시스템 및 그룹웨어 업무 체크리스트)** 소스코드가 보관된 전용 저장소입니다.

> 💡 **자금통합포털 메인 프로젝트 저장소**: [https://github.com/leesumin423/zzi_ori](https://github.com/leesumin423/zzi_ori)

---

## 📌 주요 수록 프로젝트

### 1. 🏦 퇴직연금 통합 관리 시스템 (`/퇴직연금통합관리시스템`)
- **개요**: 농협, 산업은행, 우리은행, 기업은행 등 10여개 금융기관에 분산된 퇴직연금 엑셀 데이터를 자동 파싱하여 통합 스냅샷 JSON(`data.json`)으로 구조화하고 웹 대시보드로 시각화.
- **주요 기능**:
  - 원리금보장형/실적배당형 가중평균 수익률(%p) 및 연간 예상 이자 수령액 자동 계산.
  - 만기 구간별(3개월/6개월/1년) 자산 분포 시각화 및 당해연도 만기 상품 추출.
  - KPI 카드 클릭 시 전년말 대비 이자수익 증감(▲/▼) 모달 분석 및 동일계좌 금리 변동(이상치) 자동 검증 (`findRateAnomalies`).
- **상세 가이드**: [`퇴직연금통합관리시스템/퇴직연금.MD`](./퇴직연금통합관리시스템/퇴직연금.MD) 참고.

---

### 2. ✉️ 그룹웨어 업무 체크리스트 (`/groupware-task-checklist`)
- **개요**: 그룹웨어 받은메일함 및 전자결재 4개 함을 헤드리스 크롤링(Playwright)하여 마감일 업무 문장을 자동 추출하고 바탕화면 메모지 팝업으로 안내.
- **주요 기능**:
  - 마감 키워드 문장 날짜 파싱 및 지남/오늘/이번주/차주 버킷 자동 분류.
  - tkinter 메모지 팝업 표시 및 완료 체크 항목 저장 제외.
- **상세 가이드**: [`groupware-task-checklist/README.md`](./groupware-task-checklist/README.md) 참고.
