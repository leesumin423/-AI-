## 전체 흐름 (Top-Down 작도 프로세스)

```
[차트작도 실전 강의]
1강 HTF/LTF 구분
   └─ 상장 이후 전체 흐름이 보이는 최상위 HTF 설정 → 유의미한 타점을 주는 LTF까지 단계적으로 축소
2강 추세선(저점끼리/고점끼리)
   └─ 단기·중기·장기 고점/저점 구분 → 같은 급의 고점/저점끼리 연결
3강 채널 작도·수정
   └─ 점 3개(스윙 1.5회)부터 채널 예측 시작 → 리퀴디티 스윕은 무시, 반복 이탈 시 채널 수정
4강 패턴 식별
   └─ 채널 수정을 반복하며 수렴/확산/쐐기 등 패턴으로 정제 → HTF/LTF 신뢰도 차등 적용
5강 스윙 카운팅 · SFP · MSB
   └─ 레인지 내 스윙 횟수 카운팅(5번째 근처 반전 多) → SFP·MSB로 레인지 유지/붕괴 판단
6강 패턴 심화 — 세력의 의도
   └─ 축적(하락)·분배(상승) 사이클로 패턴 방향성 확률 해석 → 거래량·미결제약정·청산 데이터로 검증

[트레이딩 교육방송]
2강 지지저항 종류 정리 (수평선 / 존 / 추세선·채널 / 지표)
   └─ 추세선·채널의 신뢰 요소 6가지, 무효화·리테스트 개념
3강 피보나치 & ABCD
   └─ 되돌림/연장/확장/투사 4종류, ABCD 3가지 타입(클래식/익스텐전), 마그넷 무브먼트
4강 FVG(IMB) & BPR test
   └─ 가격 불균형(인밸런스) 안의 FVG → 리밸런싱 → BPR 테스트 → PD Array·골든포켓으로 진입
5강 Harmonic 기초편
   └─ X-A-B-C-D 5포인트, 피보나치 비율 4개 중첩 → PRZ 테스트 컨펌 후 진입이 원칙
```

## 핵심 개념 요약

### A. 차트작도 실전 강의

#### 1. HTF / LTF (Top-Down 분석, 1강)
- **HTF(High Time Frame)**: 절대적 시간봉(주봉·일봉 등)이 아니라 **상대적** 개념. 두 시간대를 비교했을 때 더 큰 쪽.
- 같은 차트 안에서도 **기간이 긴 흐름 = HTF**, **짧은 흐름 = LTF**로 구분해 함께 사용.
- 탑다운 분석 시 최상위 HTF는 "상장 이후 전체 흐름을 다 보여줄 수 있는 시간대"로 설정하고, 유의미한 타점이 나올 때까지 LTF로 단계적으로 좁혀간다.
- **HTF ≈ 추세 파악(추세 전환) 용도**, **LTF ≈ 세부 타점(지지/저항) 용도** — 예외 있음(과거 HTF 저항이 현재 세부 타점으로 재사용되는 경우 등).
- **매매 전략**
  - HTF·LTF 추세가 **다를 때**: 반대 추세 포지션은 손익비를 위해 스탑을 타이트하게(채널 상/하단 또는 그 바깥 고점/저점 기준).
  - HTF·LTF 추세가 **같을 때**: 더 큰 구간이 열려 있으므로 R트레이딩 활용, 신뢰도 높은 큰 채널 기준으로 지지/저항 근거를 활용.

#### 2. 추세선과 채널 (2·3강)
- 추세선 = **저점끼리 이은 상승 추세선**(지지) / **고점끼리 이은 하락 추세선**(저항). 기본은 고점-고점, 저점-저점만 연결(1·4추세선 등 울프웨이브 예외 有).
- **단기/중기/장기 고점·저점**: 중기 고점 = 단기 고점들 사이에 위치, 장기 고점 = 중기 고점들 사이에 위치(저점도 동일 개념). 같은 급(단기끼리, 중기끼리)을 연결해야 의미 있는 추세선.
- **채널 성립 조건**: 정석은 점 4개(저점 2 + 고점 2, 평행)지만, **점 3개**(스윙 1.5회: 저점-고점-저점 또는 고점-저점-고점)만으로도 다음 스윙을 예측하며 선제적으로 채널을 그릴 수 있음.
- **채널 수정 원칙**
  1. 꼬리(윗꼬리/아랫꼬리)로 일시 이탈 → **리퀴디티 스윕(스탑 헌팅)** 으로 간주, 채널 유지.
  2. 이탈 후 즉시 재진입 → 아직 채널 유지, 다음 고점/저점이 채널을 지켜주는지 지켜본다.
  3. 유사한 위치에서 **반복 이탈**이 나타나면 → 채널을 수정. 수정 후에도 다음 스윙 하이/로우가 수정된 추세선에서 저항/지지받는지로 신뢰도 재확인.
- 추세선은 **하나만 쓰지 말고 저점선+고점선을 같이 그려 레인지(채널)로 활용** → 돌파/이탈 체크가 쉬워짐.
- **피보나치 채널**(평행 채널보다 추천) — 0.5 미드레벨이 지지/저항으로 자주 작동.
- **채널·레인지 내 프리미엄/디스카운트 존(ICT 개념)**: 레인지 0~1 중 0.5(이퀄리브리엄) 위 = **프리미엄 존**(매도 유리), 아래 = **디스카운트 존**(매수 유리). 전제는 "레인지가 유지된다"는 대추세 판단이 먼저 서야 함.
- **추세선 기울기 30~45도**가 신뢰도 높음. 돌파 시 **거래량 동반 여부**가 진짜 돌파 판별의 핵심(거래량 없이 밋밋하게 돌파 → 리테스트 재발 가능성 높음, MSB 리테스트로 컨펌 필요).
- **스윙 반복 횟수**: 3번까지는 지지/저항 신뢰도 유지, 4~5번째부터는 벽이 약해짐(붕괴 가능성 상승) — 채널·추세선 신뢰도 판단에 병행 체크.
- **대추세(HTF) 우선 원칙**: 채널·추세선이 서로 반대 방향(예: 하락채널 + 상승추세선)으로 교차할 때, 그 교차 위치가 프리미엄 존인지 디스카운트 존인지에 따라 매수/매도 유불리가 달라짐. 반드시 대추세 분석(레인지 유지 vs 돌파)을 먼저 하고 위치를 판단할 것.

#### 3. 패턴 (4강)
- 패턴 = "유형화된 틀". 저점-고점-저점 3점으로 채널을 먼저 그리고, 이후 나타나는 고점/저점이 예상과 다르면 **추세선을 수정**해 나가며 삼각수렴·쐐기·확산형 등 패턴을 식별해 나가는 과정.
- 반복 훈련하면 결국 "고점/저점을 하나씩 수정"하지 않고도 **차트를 보자마자 패턴을 한눈에 식별**하는 단계로 발전.
- 패턴이 바뀌면(예: 하락채널 → 대칭삼각수렴) 방향성 확률도 바뀜(하락채널의 블리시 플래그 확률 >50% → 대칭삼각은 50:50). 패턴 재식별을 습관화할 것.
- **HTF 패턴 vs LTF 패턴**
  - HTF 패턴: 신뢰도 高 → 양 끝단(레인지 상/하단)에서 **적극적 매매** 가능 (단, 적극성 ≠ 고배율/무리한 사이즈. 분할 진입·비중 조절 권장. ETF 이후 변동성 확대로 스탑헌팅 장기화 경향 주의).
  - LTF 패턴: 신뢰도 相對적으로 낮음 → 레인지 안 스윙 매매보다 **거래량 동반 돌파/이탈 확인 후 추세 전환 매매**가 더 합리적.
- **거래량**: 패턴(특히 수렴) 진행 중 거래량 감소 → 돌파/이탈 시 거래량 증가가 "진짜 돌파"의 신뢰 지표. 거래량만으로 헷갈릴 때는 **스윙 횟수**(5회 전후 반전 확률 高)를 함께 참고.

#### 4. Swing / SFP / MSB (5강)
- **스윙(Swing)**: 레인지(채널/패턴/수평 구간) 하단→상단 또는 상단→하단을 끝까지 채우는 움직임. **끝단까지 도달해야 "완료된 스윙" 1회**로 카운팅.
- **SFP(Swing Failure Pattern, 스윙 페일리얼 패턴)**: 레인지 끝단까지 도달하지 못하고 실패한 스윙. **스윙 횟수 카운팅에서 SFP는 별도로 세지 않고, 최종적으로 레인지를 완전히 채운 시점을 완료된 스윙으로 계산.**
- **스윙 카운팅 팁**: 채널/패턴을 수정하면 스윙 카운팅도 그 기준으로 다시 세야 함. 여러 패턴(예: 하락채널 vs 확산형)이 동시에 가능성 있을 때는 **가격 움직임이 더 많이 채워진 쪽의 카운팅을 우선 신뢰**.
- **울프웨이브와의 연결**: 스윙이 5번째까지 이어지면 반전(울프웨이브 패턴 등) 가능성 高. TP는 보통 1-4 추세선.
- **MSB(Market Structure Break)**: 저항 고점을 돌파 = **Bullish MSB**, 지지 저점을 이탈 = **Bearish MSB**.
  - **레인지 중간에서 만들어진 SFP 저점/고점을 깨는 MSB** → 기존 레인지 내 스윙을 마무리하러 갈 가능성 높음(신뢰도 高).
  - **레인지 끝단(3~4번째 스윙 근처)에서 나타나는 MSB** → 아직 스윙 카운팅상 레인지 리테스트 가능성이 높으므로, **완전한 컨펌(불리시/베어리시 리테스트) 전까지 과신 금지**.

#### 5. 패턴 심화 ① — 세력의 의도 (6강)
- **와이코프 가격 사이클**: 하락 = 세력의 **축적(매집)** 과정(개미 공포 → 강제 청산 → 물량 흡수), 상승 후 고점 = 세력의 **분배(이탈)** 과정(개미 환희·추격매수 → 물량 떠넘김).
- **깃발형·쐐기형 패턴(연속형)**: 상승 중 일시 조정은 세력이 저가에 재매집하려는 의도 → 원추세 방향 지속 확률 高(50~70%+). 이 확률을 깨고 채널을 돌파하면 오히려 더 강한 추세로 해석.
- **삼각수렴형 패턴은 다르게 해석**: 상승삼각(저점 높아짐)은 무조건 세력 매집이 아니라 시장 수요·호재 등 외부 힘일 수도 있음 → 확률상 상승 우세지만 반드시 리스크 관리 병행. 하락삼각(고점 낮아짐)도 매도 우세이나 절대적이지 않음.
- **패턴 무효화 신호**: 하락삼각의 하락 추세선을 돌파하면 반전형 가능성, 상승삼각의 상승 추세선을 이탈+베어리시 리테스트가 나오면 더 낮은 확률(하락) 쪽으로 더 강하게 튈 수 있음(원래 안 갈 방향으로 갔기 때문).
- **거래량·데이터 교차검증**: 저점에서 롱청산이 나타나되 미결제약정이 바로 회복되면 세력이 매수로 받는 신호(상승 우세 확률 강화). 반대로 고점 부근에서 롱청산 규모가 크고 미결제약정이 회복되지 않으면 세력 이탈(분배) 신호 → 상승삼각이어도 무리한 매수 대신 하락 추세선 돌파+리테스트+매수거래량 컨펌을 기다릴 것.

### B. 트레이딩 교육방송

#### 1. 지지저항 종류 & 추세선·채널 신뢰 요소 (2강)
- **지지저항 4대 분류**: ① 수평선(절대가격: 고점/저점/롱테일 유동성 스윕, 상대가격: 피보나치 비율), ② 존(서플라이/디맨드, 오더블록 — 세력이 매집 물량을 확보하는 구간), ③ 추세선·채널, ④ 지표(이평선, 볼륨프로파일 VAH/VAL/POC 등).
- **추세선·채널 신뢰 요소 6가지**: ①각도(35~45도가 적정), ②형성 기간(장기일수록 신뢰도↑), ③리테스트 횟수(3~4회가 최적, 5~7회부터 약화 — 3-Tap Setup 개념과 연결), ④명확도(추세선에 정확히 닿는 빈도, 단 리퀴디티 스윕 1~2회는 신뢰도 유지 가능), ⑤보조지표와의 중첩, ⑥추세선 상 가격 진폭(진폭이 클수록 신뢰도↑).
- **무효화(Invalidation)와 리테스트**: 추세선 이탈/돌파는 리테스트로 컨펌돼야 완전한 무효화. LTF에서 짧게 테스트만 주고 지나가도 HTF에서 한 번 더 리테스트가 나타나는 경우가 많으므로, LTF 진입 시 반드시 리스크 제거(본절 이동) 필요.
- **채널 트레이딩의 핵심**: 채널은 "가격 움직임의 범위"를 예측하는 도구 — 단독으로 쓰지 말고 다른 근거와 방향이 일치할 때만 활용. 채널 내부 매매 시 미드레벨(0.5, 피보나치 채널 권장)을 회귀선으로 활용, 채널 외부 이탈/돌파 시에는 대추세와 일치하는 방향의 리테스트를 기다려 진입.

#### 2. 피보나치 & ABCD (3강)
- **피보나치 4종류**: 되돌림(Retracement, 100% 이내), 연장(Extension, 100% 초과 되돌림), 확장(Expansion, 원추세 방향 재연장 — 리버스 옵션 활용), 투사(Projection, A-B-C 3점 기반 추세 기반 확장 — 파동 비율 예측에 사용).
- **작도 원칙**: 저점·고점 설정이 비율 값보다 훨씬 중요. 추세 진행 중(아직 안 끝남)이면 확장 방향, 추세가 끝나고 반전 확인되면 되돌림 방향으로 전환해서 사용해야 함. 피보나치 단독 사용 대신 기존 지지/저항·추세선과 중첩(피보나치 융합대)되는 구간을 우선 신뢰.
- **ABCD 패턴 3타입**: 클래식(AB=CD, 0.618/1.618 또는 0.786/1.272 대응짝), 익스텐전(AB<CD, 갭·장대캔들 동반 가능성↑), 레시프로칼(BCD가 먼저 나오고 ABC가 뒤에, 샤크 패턴과 연계).
- **마그넷 무브먼트(자석현상)**: B포인트 이탈/돌파 시 D포인트까지 자석처럼 이끌리는 확률 상승. 되돌림 비율이 작을수록(38~50%대, 배 패턴류) 손익비가 좋아 실전 활용도가 높음. 리테스트 1회를 거치며 강하게 이탈해야 발생 확률↑.
- **반전 타겟**: ABCD 반전은 통계적으로 A-D 구간의 0.382(Type 1) ~ 0.618(Type 2) 사이에서 주로 발생.

#### 3. FVG(IMB) & BPR test (4강)
- **인밸런스(Imbalance) = 가격 불균형**: 한 방향으로 거래가 충분히 이루어지지 못하고 밀려 올라간/내려간 구간. 언젠가 회귀해 "균형 가격"을 다시 형성하려는 경향(=밸런싱/리밸런싱) 있음.
- **FVG(Fair Value Gap)**: 인밸런스 안에서 3개 캔들 기준(개수는 절대적이지 않음), 이웃 캔들의 꼬리가 겹치지 않는 구간. 인밸런스보다 더 세밀화된 지지/저항 후보.
- **BPR(Balanced Price Range) 테스트**: FVG가 리밸런싱되어 "균형을 이룬 레인지"가 된 뒤, 그 레인지를 다시 테스트하는 구간. 뚫고 지나가면 BPR 테스트 실패(새로운 추세로 재해석 필요).
- **진입 3원칙**: ① PD Array(프리미엄/디스카운트 존) — Bullish BPR은 디스카운트 존, Bearish BPR은 프리미엄 존에서 진입. ② POI(Point of Interest) — 오더블록/디맨드/서플라이 등 지지저항 근거 중첩 필수. ③ 골든포켓(0.618) 등 피보나치 비율 — 0.5 이상, 다른 지지저항과 겹치는 컴플루언스 존 우선.
- **실전 팁**: 나이프 캐치(무근거 저점 예측 매수) 대신 LTF 리테스트·분할 매수 권장. 레인지를 돌파(1.0 초과)하면 BPR 테스트가 아니라 새로운 추세로 재분류.

#### 4. Harmonic 기초편 (5강)
- **구조**: X-A-B-C-D 5개 변곡점(샤크는 0-X-A-B-C-D). 피보나치 되돌림 3회 + 익스펜전 1회 = **4개 비율 중첩**으로 신뢰도 확보(ABCD 비율까지 맞으면 5개).
- **기본 패턴별 B/D 포인트 비율**: Gartley(B=0.618, D=0.786), Bat(B=0.382~0.5, D=0.886, 가장 이상적 0.5/0.5/2.0), Butterfly(D=0.786/1.27), Crab(D=1.618). 정확한 수치보다 "구성 원리(X-A-B-C-D를 통한 피보나치 중첩)" 이해가 우선.
- **진입 3단계 (신뢰도 순)**: ① (정석) 패턴 완성 + PRZ 테스트 컨펌 후 A-D 되돌림(0.382/0.618, Type1/Type2) 타겟팅. ② C→D 구간에 다른 근거 2~3개 중첩 시 타겟 활용. ③ (신뢰도 최저) ABCD B포인트 이탈/돌파 시 마그넷 무브먼트로 D까지 추세추종.
- **주의점**: 시작점(X, Critical Origin) 오식별이 가장 흔한 실수 — 임펄스 웨이브 중간을 변곡점으로 착각하면 안 됨. 샤크/사이퍼는 전용 툴(레시프로칼 ABCD 구성)로 그려야 오차가 없음. 자동화가 어려워(다중 비율 중첩) 수동 식별·거래량/RSI 교차검증이 중요.

## 실전 적용 체크리스트

1. **탑다운**: 최상위 HTF(전체 상장 이후 흐름) → 유의미한 LTF까지 단계적으로 좁힌다. HTF·LTF 추세가 같은지 다른지 먼저 확인.
2. **추세선**: 같은 급(단기/중기/장기)의 고점끼리, 저점끼리 연결. 저점선+고점선을 함께 그려 레인지화. 각도 35~45도, 리테스트 3~4회를 신뢰 구간으로 본다.
3. **채널**: 점 3개부터 예상 채널을 그려보고, 꼬리 이탈은 리퀴디티 스윕으로 판단(유지), 반복 이탈 시에만 수정.
4. **패턴 식별**: 채널 수정 과정을 패턴(수렴/확산/쐐기 등)으로 정제. HTF 패턴은 양끝단 적극 매매, LTF 패턴은 거래량 동반 돌파 확인 후 매매. 패턴 유형별(깃발·쐐기 vs 삼각수렴) 세력 의도 해석을 다르게 적용.
5. **프리미엄/디스카운트 존**: 레인지가 유지될 것으로 판단되면 0.5 기준 위=매도 유리, 아래=매수 유리로 포지션 방향 결정.
6. **스윙 카운팅**: 완료된 스윙 횟수를 세고(SFP는 미완료로 처리), 3~5회 근처에서는 반전/울프웨이브 가능성을 열어둘 것.
7. **MSB 검증**: 레인지 중간 SFP를 깨는 MSB는 신뢰, 레인지 끝단 3~4번째 스윙에서의 MSB는 리테스트로 컨펌될 때까지 보수적으로 접근.
8. **거래량·데이터**: 돌파/이탈 시 거래량 동반 여부로 진짜/거짓 돌파 판별. 애매하면 스윙 횟수로 교차 검증. 청산 데이터·미결제약정으로 세력의 축적/분배 여부까지 확인.
9. **피보나치/ABCD/하모닉**: 저점·고점 설정이 비율보다 우선. 단독 사용 금지 — 지지저항·추세선과 중첩되는 컴플루언스 존만 신뢰. 하모닉은 PRZ 컨펌 전 진입 금지가 원칙.
10. **FVG/BPR**: 인밸런스는 리밸런싱될 가능성이 높다는 전제로 접근하되, PD Array(프리미엄/디스카운트)·POI 근거 중첩·골든포켓 비율 3가지를 함께 확인한 뒤 분할 진입.
11. **리스크 관리**: 대추세와 반대 방향 포지션은 스탑을 타이트하게(채널 경계/직전 스윙 고점·저점 기준). 미드레벨·주요 저항/지지 돌파 시 분할 익절 및 스탑 이동(브레이크이븐) 실행.
